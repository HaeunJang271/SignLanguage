# 연구 질문

## 핵심 질문

한국수어 학습자의 손 랜드마크 시계열을 기준 동작과 비교할 때, 어떤 특징(손 모양, 위치, 방향, 움직임)과 정렬 방법(절단 정렬, DTW 등)이 전문가 교정 라벨과 일치하는 오류 진단을 가능하게 하는가?

## 범위

- MediaPipe Hand Landmarker의 사전 학습 모델을 우선 사용한다.
- 첫 단계에서 MediaPipe 자체를 파인튜닝하지 않는다.
- 단어 분류보다 동작 차이 분석과 교정 피드백을 목표로 한다.

## 비목표

- 근거 없는 정확도/숙련도 점수 산출
- 전문가 미검증 교정 규칙을 확정 기능으로 제공
- 원본 카메라 영상의 기본 서버 수집
