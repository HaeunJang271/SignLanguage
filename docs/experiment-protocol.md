# 실험 프로토콜

## 실험 A: DTW 기준선

- 입력: 정규화된 랜드마크 시계열
- 라벨: 전문가 검증 오류 유형 (확보 전 학습 금지)
- 전처리: wrist-relative 정규화
- 평가: Macro-F1, Precision, Recall, 혼동행렬 (데이터 확보 후)

## 실험 B: SVM / Random Forest 오류 분류

- 입력: DTW 거리 및 특징별 차이 벡터
- 조건: 전문가 라벨이 있을 때만 학습
- 분할: 촬영자 단위로 train/test 분리

## 실험 C: TCN / LSTM

- 데이터가 충분할 때 시계열 모델 비교

## 실험 D: 미관측 촬영자 일반화

- 학습에 포함되지 않은 촬영자에서의 성능 측정

## 현재 실행 상태

학습자 성능을 평가하는 실험은 아직 실행하지 않았다. 단일 샘플 기록의 촬영 각도 간 거리 점검만 수행했으며, 결과는 `docs/results.md`에 구분해 기록한다.

## 로컬 샘플 DTW 미리보기 구현

- 입력: `NIA_SL_WORD1501_REAL01_D` 한 클립의 OpenPose 2D 손 키포인트와 브라우저 MediaPipe 결과의 x/y 투영값
- 손 선택: 좌/우 라벨이 일치하고 유효한 21점 키포인트가 있는 프레임만 사용
- 키포인트 처리: 샘플 좌표 confidence가 0.2 미만인 프레임은 제외한다. 픽셀 좌표는 가져오기 시 영상 너비/높이로 나눠 이미지 정규화 좌표로 바꾼다.
- 정렬 및 거리: 프레임 간 평균 2D 유클리드 거리를 비용으로 고전 DTW를 수행하고 최적 경로의 평균 거리를 표시한다.
- 제한: 손목/크기 정규화와 촬영 조건 보정은 적용하지 않는다. 이 로컬 샘플에는 단어명과 전문가 오류 라벨이 없으므로 분류, 정답 판정, 모델 학습 결과로 해석하지 않는다.
- 상태: UI 실험 기능 구현. 데이터셋 연구 평가나 사용자 성능 결과는 아직 실행하지 않았다.
