## 샘플 촬영 각도 간 DTW 점검

- 입력: 사용자 제공 샘플 `NIA_SL_WORD1501_REAL01_{D,F,L,R,U}`의 동기화된 각도별 2D 손 키포인트
- 각 각도: 좌·우 손 각각 139개 유효 프레임, 1920×1080, 30fps
- 전처리: x/y를 영상 크기로 나눠 정규화, confidence 0.2 미만 키포인트가 있는 프레임 제외
- 거리: 같은 손의 프레임별 평균 21점 유클리드 거리, 고전 DTW 경로의 평균 비용
- 기준 각도: D. 이 값은 동일 기록의 다른 카메라 각도와 비교한 좌표 거리이며 학습자 정확도나 수어 정답률이 아니다.

| 기준→비교 각도 | 왼손 거리 / 정렬쌍 | 오른손 거리 / 정렬쌍 | 두 손 평균 |
|---|---:|---:|---:|
| D→D (자기 비교 점검) | 0.00000 / 139 | 0.00000 / 139 | 0.00000 |
| D→F | 0.05123 / 149 | 0.08162 / 146 | 0.06643 |
| D→L | 0.10917 / 150 | 0.05915 / 151 | 0.08416 |
| D→R | 0.03108 / 150 | 0.08001 / 171 | 0.05554 |
| D→U | 0.06987 / 147 | 0.07573 / 185 | 0.07280 |

D와의 평균 거리는 R 각도에서 가장 낮고(0.05554), L 각도에서 가장 높았다(0.08416). 이는 해당 샘플의 2D 투영 차이만 설명한다. 같은 수어 수행을 촬영한 각도 간 값이므로 카메라 시점이 수치에 영향을 준다는 점을 보여주는 점검 결과다.
