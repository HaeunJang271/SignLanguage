# 데이터 라이선스 및 출처

## 원칙

- 출처, 라이선스, 재배포/학습 허용 여부를 기록한다.
- 확인되지 않은 라이선스는 `needs_review` / "확인 필요"로 표시한다.
- 원본 영상과 민감 데이터는 Git에 올리지 않는다.
- 합성 테스트 데이터는 실제 한국수어 기준으로 취급하지 않는다.

## 현재 상태

| 항목 | 상태 |
|------|------|
| 검증된 한국수어 기준 영상 | 미연결 |
| 전문가 라벨 | 미확보 |
| 합성 좌표 테스트 데이터 | 코드 내 유닛 테스트용만 존재 |

## 로컬 개발 샘플

- 사용자가 제공하고 로컬 개발용 사용을 확인한 AI Hub `수어 영상` 샘플 중 `NIA_SL_WORD1501_REAL01_D`만 사용한다.
- 원본 ZIP과 추출 결과는 `data/private/`에 두며 Git에 포함하지 않는다.
- 가져오기 스크립트는 해당 클립의 MP4와 프레임별 좌·우 손 2D 키포인트만 저장한다. 얼굴 및 몸 키포인트와 나머지 샘플은 복사하지 않는다.
- 숫자 단어 ID의 한국어 글로스 매핑은 미확인이고 전문가 검증 상태도 미확인이다. 따라서 실제 학습 자료나 정답 기준 동작으로 표시하지 않는다.
- 개발 화면에서는 샘플과 학습자 랜드마크의 x/y 좌표만 사용해 DTW 거리 실험을 제공한다. z 깊이, 촬영 거리, 프레이밍을 비교하지 않으며 결과는 수어 정확도 점수가 아니다.
- 이 샘플의 라이선스 상태는 로컬 개발용 사용자 확인이며 재배포·공개 호스팅 허가를 뜻하지 않는다. API는 개발 환경에서만 동작하고, 정식 배포 전에는 AI Hub 데이터별 약관 및 해당 계정의 이용 조건을 따로 확인한다.
- 공식 데이터 안내: https://aihub.or.kr/aihubdata/data/view.do?aihubDataSe=data&currMenu=&dataSetSn=103&topMenu=

## 검토 예정 출처 (연결 전 이용 조건 확인 필요)

- 한국수어사전 등 공식 공개 자료
- AI Hub 수어 데이터셋 (이용 약관 확인 후)

각 출처를 연결할 때 `sourceUrl`, `license`, `licenseStatus`, `verifiedByExpert` 필드를 갱신한다.
